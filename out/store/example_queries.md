## Raw SQL: highest-confidence detection per class

```console
$ python scripts/query.py --sql SELECT class_name, frame_id, ROUND(MAX(confidence), 3) AS best_confidence FROM scenarios GROUP BY 1, 2 QUALIFY ROW_NUMBER() OVER (PARTITION BY class_name ORDER BY best_confidence DESC, frame_id) = 1 ORDER BY class_name
```
